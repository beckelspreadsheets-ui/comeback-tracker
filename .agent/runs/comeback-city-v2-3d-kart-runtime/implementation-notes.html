Decisions And Tradeoffs

  • Because the helper script is absent, the ledger was created manually using the required layout and single canonical HTML state file.
  • The worktree contains many pre-existing race and evidence changes; this goal will preserve them and layer new scoped changes on top.
  • The new runtime models V2 cards procedurally in Three.js instead of importing the trait-card PNGs as gameplay backgrounds. This preserves the PRD constraint against static screenshot worlds.
  • The old Pixi component still exists in the repo for legacy/debug reference, but /#race and /#race-3d-spike mount the new Three.js runtime and tests assert no Pixi canvas is mounted.
  • The in-app browser smoke confirmed DOM/canvas mounting; direct Playwright validation was used for telemetry reads because the in-app browser read-only evaluate scope did not surface the page global consistently.
  • After validation, track segment density was reduced from 168 to 112 samples and curb/rail/line marker intervals were widened to improve video-proof FPS headroom while preserving the same route shape and 36-prop V2 scene composition.
  • Owner rejected the initial live 3D route on visual grounds. The first repair pass swaps in generated V2 kart/facade/pickup/boost PNGs as in-scene sprites, removes the flat skyline wall, moves the finish gate out of the spawn camera, and adds an opening facade row.
